# 🌌 Aurore — Mise à jour v1.5.1

Nouvelle version du système Aurore sur Foundry ! Voici ce qui change depuis la v1.4.0 👇

## ✨ Nouveautés

**🔮 58 pouvoirs disponibles**
Le compendium des pouvoirs est enfin rempli : **24 Passifs**, **24 Navigation** et **10 Auromancie**, chacun avec son icône.
Parmi les passifs : les **Affinités** (+10 % aux jets d'équipement de RAGE, SURPRISE ou PEUR) et les **Implants** (permettent d'équiper des implants de RAGE, SURPRISE ou PEUR).
Sur la fiche, le bouton ➕ ouvre une liste avec recherche, classée par discipline : cochez ceux que vous voulez, c'est ajouté.

**🎁 26 dons communs**
Même principe pour les dons : un bouton ➕, une liste avec recherche, et vous cochez. Les dons que vous avez déjà sont grisés.

**🖼️ Fiche image aur-sheet**
Un nouveau bouton en haut de la fiche de personnage (**Générer la fiche image**) ouvre votre perso dans aur-sheet pour télécharger une jolie fiche en PNG.

**🎒 Objets divers**
Nouvelle section dans l'inventaire pour tout ce qui n'est ni une arme, ni une armure, ni un gadget (clés, documents, babioles…).

**🎲 Résultat des jets affiché**
Les jets de stats mentales indiquent maintenant clairement le résultat dans le chat : **RÉUSSITE**, **ÉCHEC**, **RÉUSSITE CRITIQUE** ou **ÉCHEC CRITIQUE**.

## 🎨 Améliorations visuelles

• L'équipement de la fiche a été réorganisé : chaque emplacement affiche directement ses infos clés (dégâts, bonus PP, utilisations) avec la couleur Trinity.
• Nouvelles icônes pour toutes les **armures** et tous les **raciaux**.
• Petites corrections de libellés et de style.

## 🐛 Corrections

• Les compendiums se rechargent correctement s'ils ont été vidés.

Bon jeu à tous ! 🚀
